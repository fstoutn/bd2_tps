# Declaración de Uso de Inteligencia Artificial (DUIA)

**Cátedra:** Base de Datos II — UTN, Tecnicatura Universitaria en Programación, ciclo 2026.
**Trabajo:** TP N.º 8 - Food Store en la feria.
**Integrantes:** Ponce De Leon Leonel; Storani Franco; Pinto Guillermo; Soto Matias.

Declaramos que para la preparación del TP8 utilizamos **ChatGPT (GPT-6)** como asistencia para estructurar esquemas, consultas y scripts SQL, explicar restricciones, organizar documentación, generar pruebas reproducibles y preparar el informe. Las pruebas de SQLite fueron ejecutadas localmente mediante el módulo `sqlite3` de Python; sus resultados verificables figuran en `tests/resultados_verificados.json`.

En esta preparación no conectamos nuestra instancia original de PostgreSQL ni ejecutamos la revisión en OpenCode Plan o la spec en Kiro; dejamos esos pasos identificados como **pendientes** hasta realizarlos. Ningún estado `SIMULADO_APROBADO` fue tratado como venta confirmada.

Los datos de prueba se diseñaron como ficticios. El modelo de MongoDB y los nombres del grupo se retomaron del TP7 aportado. No se solicitaron credenciales ni se incorporaron datos personales reales en SQLite.

Esta declaración registra nuestro uso efectivo. Antes de presentarla debemos contrastarla con el **formato oficial de DUIA de la cátedra**, que no estaba disponible en los materiales adjuntados, y firmarla si corresponde.
