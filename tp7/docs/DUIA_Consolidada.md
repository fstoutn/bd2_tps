# Declaración consolidada de uso de inteligencia artificial (DUIA)

**Equipo:** Ponce De Leon Leonel, Storani Franco, Pinto Guillermo, Soto Matias. **Materia:** Base de Datos II — TPI segunda entrega.

El equipo informa uso de asistentes de IA durante el desarrollo y la documentación de las unidades 4–8, con los siguientes respaldos:

- **U4:** el informe describe los scripts de descomposición BCNF y vista materializada; 
- **U5:** `TP Unidad 5/BITACORA.md` detalla solicitudes a GitHub Copilot y OpenCode sobre permisos, auditoría, incidente y anonimización; se conservan respuesta y contraste humanos. Se descartaron permisos automáticos excesivos sobre objetos futuros.
- **U6:** Declara asistencia de OpenCode y GitHub Copilot para especificaciones y scripts de respaldo; validación humana en PostgreSQL 17.11. No encontramos registro de automatización programada efectivamente ejecutada.
- **U7:** el material incluye consultas MongoDB/PostgreSQL y evidencia.
- **U8:** `tp8/docs/DUIA.md` y `tp8/docs/bitacora_ia.md` declaran uso de ChatGPT para artefactos del TP8, con tests SQLite.
- **TPI consolidado:** se utilizó ChatGPT (GPT-6) para revisar documentalmente el repositorio adjunto, detectar hallazgos reproducibles, estructurar el informe, matriz de evidencias, guías y esta declaración. Se realizó una auditoría estática, **no** una ejecución de OpenCode/Kiro ni de PostgreSQL del grupo.

**Protocolo:** utilizar datos sintéticos/anonimizados; no incluir claves ni datos sensibles; revisar línea por línea y probar sobre copia antes de ejecutar los scripts nuevos.
